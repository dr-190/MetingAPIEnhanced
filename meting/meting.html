API 文档

参数说明

参数 说明
server 数据源：netease（默认）｜tencent｜xiami｜kugou｜baidu｜kuwo（当前仅 netease，其他静默忽略）
type 请求类型：name｜artist｜url｜pic｜lrc｜song｜playlist｜search
id 歌曲/歌单 ID；type=search 时为搜索关键词
br 音质（仅 type=url，默认 320，可选 2000/flac/192/128）
cover 封面分辨率（仅 type=pic，默认 300；兼容旧参数 size）
limit 搜索条数（type=search，默认 30）
page 搜索页码（type=search，默认 1）

接口列表

GET /meting/?type=search&id=关键词&limit=10
搜索歌曲，返回 JSON 数组
GET /meting/?type=song&id=歌曲ID
获取歌曲详情，返回 JSON 数组
GET /meting/?type=playlist&id=歌单ID
获取歌单，返回 JSON 数组
GET /meting/?type=url&id=歌曲ID&br=320
获取播放链接，302 重定向
GET /meting/?type=pic&id=图片ID&cover=300
获取封面图，302 重定向
GET /meting/?type=lrc&id=歌曲ID
获取歌词（含中文翻译），返回纯文本
GET /meting/?type=name&id=歌曲ID
获取歌曲名，返回纯文本
GET /meting/?type=artist&id=歌曲ID
获取歌手名，返回纯文本

VIP 解锁

Cookie 透传

要使用 VIP 功能，在请求头中传递 Cookie：Cookie: MUSIC_U=你的token

GET /meting/?type=url&id=歌曲ID
Header: Cookie: MUSIC_U=00D6706E17E980...

无需 Cookie 时，灰色歌曲会自动尝试解灰。
