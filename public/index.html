MetingAPIEnhanced

基于 NeteaseCloudMusicAPI Enhanced 的 Meting 协议兼容层

特性

Meting 协议兼容

完全兼容 injahow/meting-api 协议，支持 APlayer/MetingJS 集成

Cookie 透传

每次请求的 Cookie 头都会传给网易云，VIP 即时生效

自动解灰

灰色歌曲自动解锁，底层走 unblockmusic-utils

随机中国 IP

支持随机中国 IP，weapi/eapi/xeapi 多套加密

快速开始

# 克隆项目
git clone https://github.com/your-username/MetingAPIEnhanced.git
cd MetingAPIEnhanced

# 安装依赖
npm install

# 配置环境变量
cp .env.example .env

# 启动服务
npm start
API 测试页面 GitHub 仓库

API 接口

GET /meting/?type=search&id=关键词&limit=10
搜索歌曲，返回 JSON 数组
GET /meting/?type=song&id=歌曲ID
获取歌曲详情，返回 JSON 数组
GET /meting/?type=playlist&id=歌单ID
获取歌单，返回 JSON 数组
GET /meting/?type=url&id=歌曲ID&br=320
获取播放链接，302 重定向
GET /meting/?type=pic&id=图片ID&cover=300
获取封面图，302 重定向
GET /meting/?type=lrc&id=歌曲ID
获取歌词（含中文翻译），返回纯文本

参数说明

参数 说明
type 请求类型：name/artist/url/pic/lrc/song/playlist/search
id 歌曲/歌单 ID；search 时为搜索关键词
server 数据源：netease（默认），其他值静默忽略
br 音质：128/192/320/2000(FLAC)，默认 320
cover 封面分辨率，默认 300
limit 搜索条数，默认 30
page 搜索页码，默认 1
search_type 搜索类型：1 单曲/10 专辑/100 歌手/1000 歌单

VIP 支持

要使用 VIP 功能，在请求头中传递 Cookie：

curl -H "Cookie: MUSIC_U=你的token" https://your-domain.com/meting/?type=url&id=歌曲ID

无需 Cookie 时，灰色歌曲会自动尝试解灰。

更新 api-enhanced

cd /www/wwwroot/Metingapi/MetingAPIEnhanced
rm -rf api-enhanced
git clone --depth 1 https://github.com/neteasecloudmusicapienhanced/api-enhanced.git api-enhanced
cd api-enhanced && npm install && cd ..

我们的文件（meting/、server.js、app.js、.env）不会被覆盖。
