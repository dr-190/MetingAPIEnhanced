Meting API 新增

完全兼容 injahow/meting-api 协议，支持 APlayer/MetingJS 集成

  • Meting API 测试页面
  • 搜索歌曲: GET /meting/?type=search&id=关键词
  • 歌曲详情: GET /meting/?type=song&id=歌曲ID
  • 歌单: GET /meting/?type=playlist&id=歌单ID
  • 歌词: GET /meting/?type=lrc&id=歌曲ID
  • 播放链接 (302): GET /meting/?type=url&id=歌曲ID
  • 封面图 (302): GET /meting/?type=pic&id=歌曲ID

参数说明

GET /meting/?type=search&id=关键词&limit=10&search_type=1
搜索类型: 1 单曲 / 10 专辑 / 100 歌手 / 1000 歌单
GET /meting/?type=url&id=歌曲ID&br=320
音质: 128 / 192 / 320 / 2000(FLAC)
GET /meting/?type=pic&id=歌曲ID&cover=300
封面分辨率: 300 / 500 / 1000
